# Software Test Plan

Put the Software Test Plan here. Base it on [`../course-material/Test_Plan_Template for SE.docx`](../course-material/).

What the Part-1 deliverables require:
- IEEE format: introduction and the other descriptive sections, with sections 3, 4 and 5 filled in
- Section 5.1, security validation
- Traceability back to the SRS requirement IDs
- At least 7–10 test cases, covering both functional and non-functional requirements

The SAD traceability table (§3.8) already uses these test-case IDs: `TC-AUTH-xx`, `TC-SLOT-xx`, `TC-BOOK-xx`, `TC-SESS-xx`, `TC-BILL-xx`, `TC-PAY-xx`, `TC-TRK-xx`, `TC-ADM-xx`, `TC-RPT-xx`, `TC-NOTIF-xx`, `TC-PERF-xx`, `TC-REL-xx`, `TC-UI-xx`, `TC-SEC-xx`.
